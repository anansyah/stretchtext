StretchText settings

StretchText reads with your own Pollinations key. The key stays in sessionStorage for this browser session and is never bundled with the extension.

Pasting a key here skips the Connect button. Leave it empty and use “Connect your Pollen” in the toolbar so the extension only ever gets a scoped, revocable key. The live list is at gen.pollinations.ai/text/models. Any text model name works.
